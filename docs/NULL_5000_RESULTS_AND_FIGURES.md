# Final 5,000-refit result and manuscript update (24 September 2026)

The exploratory, non-preregistered null continuation is complete: 5,000 seeded nested refits for each of 72 tests (two overlapping sleep portfolios × three representations × three controls × four metrics). The observed analyses were unchanged. The count was fixed after reviewing the initial 100-refit results, so this is a post-results resolution extension, not preregistered confirmation.

Four tests survive Holm correction across all 72 comparisons: sparse-core sensor representation under temporal permutation for absolute dynamic log loss and dynamics-minus-conventional, dynamics-minus-nonlinear-scalar, and dynamics-minus-spectral losses. Each has raw lower-tail p = 1/5,001 = 0.0001999600 and Holm p = 0.01439712. These four metrics share the same representation and temporal control, so they are not four independent replications. Five of 36 sparse tests have raw p < 0.05; four survive the full-family correction. Sparse sensor label-permutation absolute loss has raw p = 0.00659868 but Holm p = 0.44871026, and its conventional-comparator difference has raw p = 0.56388722. The sparse sensor phase-randomized absolute-loss test has raw p = 0.07118576.

No high-density test has raw p < 0.05 (minimum raw p = 0.13597281); every high-density Holm p is 1. The high-density portfolio overlaps the sparse one and differs in study/report composition, so it is neither an independent replication nor a matched electrode-density test. The training-only constant predictor remains better in mean absolute loss than each trajectory model in both portfolios. These results support a limited sparse sensor temporal-specificity finding, not a transferable or clinically useful consciousness marker.
